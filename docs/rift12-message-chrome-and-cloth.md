# 界隙 0.5.0-rift.12：纯文字状态与衣服动画边界

延续 `0.5.0-rift.11` 已确认的画面，保持素材、普通消息气泡和建筑动效不变。

## 修正

- 整个回写尾部容器不再套用通用内容底色（包括状态尚未加载的空容器），状态和操作仍然保留。
- 日期及消息操作栏不加底色、边框或阴影；解除正文描边继承。
- 排除原生 Tooltip 的同名 `bubble` 类，避免被消息气泡选择器误伤。
- 会话内复制悬浮提示采用纯文字、深浅主题对应字色和轻微文字阴影，不加气泡底色。
- 移除手部摆动，仅在袖口下缘和衣摆产生布料位移。
- 双臂固定区域作用于最终位移，防止邻近建筑或衣摆动效再次牵动皮肤。

## 验证

- `npm test`：154 通过、1 旧测试跳过、0 失败。
- `scripts/verify-rift-message-chrome.mjs`：深浅模式与 390 / 1440 宽度；回写、日期、复制提示无气泡；hover / 键盘焦点与重试按钮可用。
- `scripts/verify-rift-motion-pins.mjs`：实际 WebGL 执行位移着色器，在 5 个时刻确认手指、手掌、前臂和另一侧胳膊采样位移为零，袖口、衣摆和建筑仍有位移。
- 浏览器脚本通过 `XIAOHEI_PLAYWRIGHT` 指定现有 Playwright 模块，不新增生产依赖。

透明文字覆盖复杂壁纸无法保证每个像素都满足固定对比度；使用主题对应的高对比字色与轻微文字阴影，不宣称透明背景下的全图 AA 保证。
