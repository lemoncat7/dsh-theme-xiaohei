# 淡蓝玻璃与空间印记（2026-10-21）

本轮统一主题的语义色、气泡、输入框、弹窗及交互高光。浅色为冰蓝阅读面，深色为蓝灰阅读面；不对人物原画整体染色，不改错误、警告等业务状态的含义。

- 上栏及左栏为 16px 圆角玻璃；模糊只作用于不接收鼠标的伪元素，不在固定弹窗祖先上增加 filter、transform 或裁切。
- Logo 恢复老主题的原始造型及液态金属材质。`scripts/render-original-brand.mjs` 读取 `metallic-brand-mark.tsx` 的原始着色器、参数、固定时间及 `xiaohei-brand-head-v2.webp`，按原先 .28/.92 图层透明度预渲染 256px WebP。保留银黑反射，无运行时 WebGL、无重绘、无外环；源文件/材质结果的哈希由测试校验。仅用于侧栏及空会话，启动加载不显示 Logo 或头像。
- 首屏只修饰 DSH 的 `[data-dsh-boot-spinner]`，使用流光汇聚、光点穿行和空间光缝，不再使用黑洞头像或转圈卡片；保留原生状态文字和错误处理，没有自建进度、观察器或延时。仅两张装饰平面执行 transform/opacity 动画，减少动态时静止。
- 人物继续仅保留耳朵和呆毛动作；不重新启用衣服、普通头发、手臂或右下建筑运动。已接受的轮廓扩散交互保持不变。

验证：`npm test`；`scripts/verify-rift-blue-boot.mjs`、`verify-rift-glass.mjs`、`verify-rift-message-chrome.mjs`、`verify-rift-impulse.mjs`。浏览器脚本需要配置 `XIAOHEI_PLAYWRIGHT` 和 `PLAYWRIGHT_BROWSERS_PATH`。

部署必须同时更新 `lib/index.js` 和三个客户端 chunk，仅更新客户端不会改变插件加载前的首屏。正式部署前分别备份原文件，保留数据卷及其他插件。

## 外观首屏与系统跟随

- DSH 0.2.1-rc.2 的主题运行时会先发布默认 `system`，随后才读取已保存外观。正式环境已复现：保存深色、浏览器偏好浅色时，首屏深色被默认值短暂切成浅色，再恢复深色。
- 启动样式携带服务端的已保存偏好；设置仍处于 `loading` 时保持该偏好，通过公开的成对 token 覆盖保证界面与壁纸一致。设置就绪后立即移除临时覆盖，不使用固定延时，也不写回用户偏好。
- 系统模式读取浏览器 `prefers-color-scheme`，监听媒体变化、页面恢复及可见性变化。明确选择浅色／深色不受系统变化影响。浏览器若上报浅色，系统模式应保持浅色，不能根据时间或平台名称擅自猜测。
- `scripts/verify-rift-appearance.mjs` 使用原版 `ThemeRuntime` 和隔离的内存设置验证深浅首屏、设置加载交接、系统双向切换与释放；不会修改正式环境设置。

## 展示模式：整套外观切换

- 左下角「界隙外观」提供完整界隙、柔和渐变、纯色专注。不是只更换背景：完整模式使用原界隙样式，另外两种模式切换到独立的 `quiet-styles.ts`，不加载界隙玻璃、斜角、刻线、光晕及装饰字体规则。顶栏／两侧栏、消息气泡、输入框、按钮、选中态、菜单和弹窗整套统一。
- `quiet-palette.ts` 统一管理渐变／纯色 × 深浅色的四套色板，并通过 DSH 公开 token 覆盖同步原生控件。渐变为雾蓝材质、对称圆角；纯色为中性灰阶、平整材质、细边框。保留状态色含义，不覆盖错误／警告色，不更改原生布局、审批、会话或外观偏好。
- 选择立即生效并保存在当前浏览器 `dsh-theme-xiaohei/rift-view`，同源标签页同步；存储不可用时本页仍可切换。完整模式单独记住原有动效开关，回切不强制开启动效。
- 简洁模式实际卸载背景、嘿咻、轮廓交互的生命周期；异步资源晚到不会重新挂载。初始简洁模式不请求装饰 chunk。
- 首屏增加一段只读、白名单校验的同步 localStorage 读取，确保刷新不会先露出人物及加载特效。无计时器、网络请求或会话写入。
- 原生 dialog + radio 保证焦点管理、方向键、Esc、点击遮罩关闭；只有即时设置，无多余保存／确认按钮。
- 验证：单元测试及 `scripts/verify-rift-view.mjs`（真实 React 控件，375/1440 宽度、深浅主题、刷新记忆、生命周期、键盘和焦点恢复）。浏览器测试额外接受 `XIAOHEI_REACT_DOM` 指向测试环境已有的 react-dom/client.js，不引入生产依赖。
- `scripts/verify-quiet-theme.mjs` 检查整页八种组合，验证控件实际材质、边框、圆角、折叠历史、模式恢复及截图；单元测试逐项核验正文／次要文字在各阅读面上的对比度、原生 token 完整性及设置加载期间的选定色板。
