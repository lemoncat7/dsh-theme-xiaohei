# 0.3.1

正式版，包含 0.3.0 的壁纸、侧栏和嘿咻交互更新，以及部署验收后的两项修复。

## 本次修复

- 侧栏玻璃跟随实际可见栏位宽度，在绘制前同步更新，修复收放时背景提前展开、滞后收缩的问题。
- 启动配色只在初始化期间短暂保留，不再阻止后续官方主题事件；即使没有新事件，也会释放过期的启动标记。
- “跟随系统”遵循当前设备／浏览器报告的配色偏好，不按服务器时间切换。

## 本系列更新

- 日夜天空壁纸与高清罗小黑角色分层；宽屏坐姿、窄屏探头，保留托腮和打盹姿势，人物不再跟随输入框下沉。
- 统一侧栏磨砂材质、目录和会话状态，增大消息气泡横向留白，保留原生布局和业务操作。
- 输入框旁嘿咻支持慢浮动、鼠标视线、点击／双击动作、随机待机，以及可选的当前会话思考和结束提醒。
- 修复嘿咻随输入框下沉时飞行动画重复打断、重启的问题，并增强抬头幅度；发送键嘿咻保持独立。
- 背景独立于会话状态；动画支持隐藏暂停、减少动态及卸载清理，素材按需解码、特效节点复用。

## 验证与兼容性

- DeepSeek Harness `0.1.2-rc.1`；Node.js `^22.19.0 || >=24.0.0`。
- 自动测试 84 项：83 通过，1 项历史测试跳过。
- 部署后已验证深浅色、系统配色切换、桌面和手机横竖屏、侧栏收放、减少动态模式及发送键保留，无页面脚本错误。
- iOS／Android 软键盘仍需真机补充验收；浏览器测试不代表所有设备的帧率表现。
