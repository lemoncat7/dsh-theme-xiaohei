# v0.3.2

正式版本，适配 **DeepSeek Harness v0.1.2-rc.1**，需要 Node.js 22.19+ 或 24+。npm 使用 latest 标签。

## 更新

- 人物耳朵使用独立耳根旋转；坐姿和托腮的尾巴通过 7 个关节点及网格蒙皮连续变形，支持鼠标靠近联动。
- WebP 只作静态图层，不播放动作帧条。眨眼仍采用眼睑贴图合成，身体与四肢没有完整骨骼绑定；不是完整 Live2D，不引入 GLB、Three.js 或额外运行时依赖。
- 动作最高 30 帧，静止停绘，后台、无安全位置及减少动态模式暂停。
- 修复侧栏展开时文字抢先出现：根据实际列宽统一淡入，支持快速反向切换。
- 侧栏移动期间暂停角色布局与绘制；小图标缓存金属画面，避免宽窄切换反复重建 WebGL 和编译着色器。
- 保留原生布局、侧栏配色、磨砂和插件业务功能。

## 安装

```sh
dsh plugin --profile web add @lemoncat7/dsh-theme-xiaohei@0.3.2
```

或下载本 Release 的 tgz 完整包后安装。

## 验证

94 项测试：93 通过、1 项历史跳过、0 失败。浏览器检查覆盖深浅配色、角色四种姿势、侧栏文字逐帧时序、快速开合、手机横竖屏及减少动态模式。真实移动设备的帧率与软键盘行为仍建议实机验收。
