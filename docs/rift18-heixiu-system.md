# 界隙 0.5.0-rift.18：保留嘿咻，核验跟随系统

## 嘿咻

按用户要求恢复输入框旁原有的嘿咻：漂浮、鼠标响应、点击互动、双击/Shift+Enter 变形、当前会话的运行/完成提示。仅接回这个独立模块，不恢复旧壁纸、旧侧栏、发送按钮替换或已经取消的耳朵/流光/浮动框。

- `client.companion.js` 是独立的原生 DSH 延迟分包，等待输入框出现且首帧绘制后加载。
- 主入口约 51.6KB，嘿咻分包约 45.4KB；未增加依赖或提前加载旧素材。
- 窄屏使用紧凑位置，不接管发送操作。会话状态走原有只读订阅，不读聊天正文、不请求历史。
- 原生输入框按钮样式排除嘿咻，保留它自己的圆形交互区域。

## 外观跟随系统排查

线上初始保存的外观为 `dark`，并非 `system`。通过真实设置按钮临时切到“跟随系统”，使用浏览器环境模拟验证：

1. 浅→深→浅：DSH 原生 `colorScheme`、body 深色标记、主题外观属性、壁纸外观均同步。
2. 刷新：`system` 选择保留，壁纸及主题仍为系统浅色。
3. 手动选择浅色后模拟系统深色：维持用户手动浅色。
4. 测试结束恢复原来的深色偏好。

未复现主题切换缺陷，因此未增加第二套 matchMedia 判定或覆盖 DSH 偏好的代码。以上是服务端浏览器测试结果，不代表已验证用户另一台桌面客户端的系统设置。
