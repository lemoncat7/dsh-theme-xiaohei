# 独立浅色场景 · 0.5.0-rift.5

纠正 rift.4 的浅色适配：浅色模式不再使用深色背景与深青消息块。

- `src/assets/rift/scene-light.webp`：DSH 生图插件生成的浅色配套原画，1672×940，70,594 字节。
- 深色继续使用 `scene.webp`，未改其图像与材质。
- 浅色为银白雾境、淡青裂隙、银色金属碎片与白发人形小黑。
- 消息、草稿、状态、代码、回写提示均采用浅色表面与深色文字。
- 首屏 CSS 按系统外观选择背景，DSH 外观生效后以其为准；无额外启动脚本。
- 模式切换替换单个场景的图像与纹理，释放旧渲染资源，不叠加两套场景。浅色灵光采用青色透明混合，避免加法混合导致看不见。

生图渠道：用户授权的 DSH `generate_image` 插件，配置模型 `gpt-image-2.5`；非内置 image_gen，也未使用 OpenAI CLI 回退。

完整请求及最终提示词：`output/imagegen/xiaohei-rift-light-20261017/request.json`（工作区根目录）。

提示词目标：保留原图角色身份、白发、绿眼、姿态、服装及构图；将黑色环境重新绘制为银白日光雾境，保留安静的左侧阅读空间与空间裂隙，禁止白色蒙层替代重绘、黑色暗角、文字和额外角色。
