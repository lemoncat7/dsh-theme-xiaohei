# 0.5.0 · 界隙主题 · DSH 0.2.1-rc.2

## 兼容要求

- 适配 DSH **0.2.1-rc.2**，声明范围 `^0.2.1-rc.2`。
- Node.js **^22.19.0 或 >=24.0.0**。旧宿主请保留对应旧版主题。
- 更新后重启 DSH Profile 并刷新页面；无需修改官方核心代码。

## 本版更新

- 白发人形小黑与深浅独立场景，淡蓝玻璃上栏、侧栏及会话材质。
- 完整界隙、柔和渐变、纯色专注切换整套外观，而不只替换壁纸。
- 保留耳朵、呆毛和嘿咻动态，固定身体、手臂、衣服与建筑。
- 恢复金属质感标志、轮廓扩散交互，调整首屏加载及外观偏好衔接。
- 修正会话元信息、工具区与回写状态的主题表现。
- 装饰独立延迟加载，后台暂停；减少重复背景绘制、相同尺寸画布重置及无变化的区域更新。

## 验证与边界

- Node.js 22 构建及测试：189 项通过，1 项跳过。
- 本次性能修复已部署，容器健康检查通过，线上浏览器构建哈希与本地一致。
- 未量化用户浏览器刷新提速；不同 GPU、移动端与桌面端仍需实际体验验证。
