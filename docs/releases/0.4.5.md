# 0.4.5 · 对话输入预览与主题按需加载

兼容宿主：DeepSeek Harness 0.2.0-rc.2。本版本不调整宿主兼容范围。

## 对话体验

- 输入时显示草稿气泡，跟随正式对话内容列对齐；清空、切换会话后同步更新。
- 适配宿主发送后的提前回显及插话消息，统一气泡、头像和浅深色样式，保留附件及排队操作。
- 覆盖窄屏、长文本与安全文本渲染；草稿预览不会代替实际发送。

## 启动与人物资源

- 壁纸随主题入口同步安装，不等待人物下载，减少首屏只有纯色背景的等待。
- 装饰和人物控制器使用 DSH 原生异步分包；按当前姿态、主题及动作设置加载对应资源，支持请求去重与缓存。
- 保留原始素材，新增 44 张有损 WebP 运行时副本，资源从约 4.44 MB 降至 0.68 MB，减少约 85%；尺寸和透明通道保持不变。
- 构建校验源图与运行时副本的 SHA256，防止发布过期素材；生成 10 个姿态和 8 个动作分包。
- 动作资源加载失败时保留静态人物；卸载及姿态变化时丢弃失效的异步结果。

验证：构建通过，113 项测试通过、1 项原有跳过；草稿预览、发送回显及头像、首屏壁纸的浅深色与窄屏/宽屏浏览器回归通过。

验证环境为 Web / DSH 0.2.0-rc.2；未进行 Desktop 实机回归。上述优化不代表所有插件加载和服务端等待均已消除。详细测量及部署记录见 `docs/startup-audit-20261013.md`。
