# 0.3.4

已在 DSH 0.1.5-rc.1 部署验证；Node.js 22.19+ 或 24+。开发依赖仍为 DSH 0.1.2-rc.1，不声明其他版本已经完整验证。

- 修复新版侧栏品牌与收放按钮识别，避免展开动画误隐藏宿主按钮。
- 调整侧栏磨砂透明度，保留原生布局。
- 原图睫毛连续变形眨眼，修正重复黑框、眼周色块和瞳孔残留。
- 瞳孔平滑跟随鼠标，移出窗口后回正，静止后停止绘制。
- 耳根固定、耳尖摆动，限制随机调度导致的动作长期缺席。
- 后台、减少动画模式与卸载均停止相应动画和监听；嘿咻发送键保持不变。

验证：101 项测试通过、1 项跳过；四种人物姿势及深浅主题浏览器回归；知识库、SSH、伙伴面板部署冒烟检查正常。
