# 0.4.6 · 对话首屏与人物交互性能优化

适配 DeepSeek Harness **0.2.0-rc.2**；需要 Node.js **^22.19.0 或 >=24.0.0**。不调整宿主兼容范围。

## 本次改进

- 输入区人物引擎拆为独立分包，在对话输入区出现并完成首屏绘制后加载，减少主题入口的同步初始化工作。
- 合并宿主 DOM 变化通知，跳过不影响输入区位置的流式正文更新、人物自身效果和历史滚动，减少重复布局测量。
- 人物挂载后延后一帧定位，先读取宿主布局再写入样式；通过输入区尺寸计算人物位置，避免写样式后立即测量造成同步布局。
- 保留欢迎页、窄屏、会话切换、窗口缩放、减少动画和卸载清理行为，不修改对话内容、发送逻辑或用户设置。

## 验证与升级

- 构建及单元测试：119 项通过、1 项原有跳过，无失败。
- 隔离浏览器回归覆盖 375 / 1280 像素、浅深主题和减少动画，共 8 种组合；检查流式更新、历史滚动、输入区替换、人物定位和清理，不向生产会话发送消息。
- 无数据迁移；升级后重启对应 Profile 并刷新页面，以加载新的异步分包。
- 本次验证针对 Web，未进行 Desktop 实机回归；优化不代表服务端或其他插件的等待均已消除。
