# 嘿咻交互参考（alpha.170–alpha.176）

## alpha.176 飞行连续性与独立壁纸定位

- 修复同一终点被 resize/scroll 反复 cancel/restart：读取缓存的视口轨迹，用当前动画进度还原布局终点；相同终点及半像素边框收敛继续原动画。实际改换终点保留当前位置和剩余时长，不重新加满 950ms。
- 飞行容器不再叠加 CSS transform transition，按压反馈下放至内部 SVG；DOMRect 按坐标显式复制，避免其原型 getter 在展开复制时丢失。
- 向上看最大俯仰由实际 2° 提升到 24°，仍由原引擎平滑投影，向下和左右范围保持克制。
- 罗小黑壁纸角色的纵向位置仅使用窗口/侧栏边界，不再依赖输入框 top 或聊天滚动区 top。欢迎页和聊天页采用相同横向内容足迹；输入框高度变化不触发角色重定位。原有宽屏坐姿、窄屏探头及闲时托腮/打盹保留。

## alpha.175 表情、休眠和会话反馈

- 复用原 bloub 的 wink / wide / exclaim / alert / sleep / thinking / notify，而非另画贴图。单击第四个动作是惊讶，双击可手动预览全部动作。
- 随机待机只包括四种已有变形、wink / wide / sleep；思考和通知不随机假触发。休眠遵循原作引擎的小点轻跳，不是新增闭眼 Zzz 素材。
- `signals.ts` 只读订阅官方当前会话快照，只向运行时发布必要的状态变化，不读取全文、不发 RPC、不新增请求/轮询。没有服务仍可正常玩待机动作。
- 运行中持续三点思考；本轮结束单次 notify；新错误单次 alert。切换/历史重载以新基线开始，无历史提醒；隐藏时丢弃新提醒，恢复只同步当前运行态。手动停止可能也属于“本轮结束”，不标注为成功。
- 通知使用暖金徽点、SVG luminance mask 透明缺口；半径随形变连续开合。效果池只分配一次，空心眼增加投影间距约束，默认轮廓和眼圈尺寸保持。
- 发送键、背景、浮游轨迹与欢迎页飞行逻辑不改。

## 原作画面观察

参考视频：[《罗小黑战记》第四集 ED / 带剧情片段转载](https://www.bilibili.com/video/BV1HT8czaEQM/)。2026-09-05 获取公开视频并抽帧查看；视频约 80 秒，参考时间以此转载为准。

- 约 15.5–22 秒：床脚旁的小黑团近景，观察圆钝轮廓、大比例浅色眼圈、闭眼及转动视线。
- 约 60 秒：ED 中短暂出现的小黑团，补充轮廓与表情参考。
- 不把视频中有完整猫耳、猫身的小黑形态直接套给输入框里的嘿咻。

这些镜头不足以证明所有交互动作。此次眨眼回应、轻跳、歪头属于基于角色轮廓和表情特点设计的 UI 动作，不宣称逐帧复刻原作。视频和抽帧图片仅作本地研究，不打包进插件。

## alpha.170 校正记录

- 旧版静止宽高比约 1.315，点击压缩时约 1.75，导致长期呈现软饼外观。新版轮廓接近圆形，测试限定静止比值 0.97–1.08；动画相对横纵缩放比低于 1.14。
- 增大眼圈，保留黑色内眼和奶白描边。眼睛与黑色身体共用稳定 SVG，不通过整帧图片/透明度切换眨眼。
- 只有起跳蓄力和落地使用少量 squash/stretch。眨眼、歪头各有独立节奏。
- 保留 bloub 的 64 点径向形变、球面视线投影和自定义表情 API；角色的反应轨道与上游状态机分离。
- 去掉 UI 中的六边形、蛋形、彩色轨道、散开重聚入口，删除呈现层不再需要的粒子/轨道节点。
- 保形 Hermite 插值使上升、下降经过中间关键帧时保持速度连续；最高点与落地正常减速，连续点击接续当前姿态。

## alpha.171 比例复核

用户反馈 alpha.170 身体太高、看起来别扭。等宽等高并不是原作比例标准，上一版对偏扁问题修正过度。

- 身体纵向半径从 1.02 调至 0.89（约降低 13%），横向基础半径保持 1。当前轮廓宽高比测试范围为 1.16–1.24。
- 眼睛高度从 0.62/0.60 调至 0.48/0.465，轻微增加宽度；正视投影后的高宽比测试范围为 1.15–1.35，避免长胶囊形眼睛。
- 两侧小凸起移近水平中线，并减小幅度，避免靠近太阳穴的头型轮廓。
- 身体与眼睛分别调整，不整体缩放 SVG。压缩/旋转支点取实际轮廓最下方，避免高度改变后脚底漂移。
- 不增加、删除或重排现有动作；不改变按钮尺寸、输入区布局、发送键或其他主题样式。

## alpha.172 恢复 bloub 特殊动作

按用户要求，在不改动 alpha.171 静止比例的前提下恢复 `burst / egg / orbit / hexagon`。这是 bloub 原项目的动作，不是罗小黑原作逐帧动作。

- 单击保留原有三种小动作；双击或 Shift+Enter 轮换四种特殊动作。遵守上游最短完整时长，结束后由原引擎渐变回自定义默认轮廓。
- 手势轨道用 220 ms 从当前姿态收回，不突然 reset；特殊动作暂时接管视线，结束后恢复鼠标互动。
- 首次显式触发时建立固定大小的装饰池，此后只更新属性。空闲初始化仍只有 10 个 SVG 节点；特殊动作使用过后共 98 个。
- 连续双击直接从当前特殊动作接续，首击不先切回 idle；无延迟点击定时器，无自动轮播。
- 补充节点复用、特效消失、键盘入口、完整复原、动作边界和快速打断检查。

## alpha.173 左侧浮动与轻微吸附

- 增加独立的 span 视觉层承载 8 秒往返慢浮动，SVG 自身承载鼠标吸附，原角色形变与反应轨道无需改动。
- 宽屏浮动 ±2 / ±3 px，吸附上限 5 / 3.5 px；窄屏浮动 ±1 / ±1.5 px，吸附上限 2 / 1.5 px。
- 吸附以静止按钮中心测量，在 140 px（窄屏 90 px）范围内平滑衰减到零，不从移动中的图案反算鼠标距离，避免追逐反馈和边缘跳变。
- CSS transform 负责视觉位移，指针事件只更新目标变量，无新增 JS 动画循环；离屏与后台暂停，减少动态模式完全关闭此层动态。
- 鼠标离开、触摸输入、布局改变及暂停时清除吸附目标。点击区域保持静止，减少跟随时点不中的情况。

## alpha.174 欢迎页落点、飞行与随机动作

- 欢迎页读取主题在官方 `conversation.hero.brand.mark` 槽位渲染的品牌元素，以它的实际位置计算左侧落点；手机标题行增加左侧预留，避免挤压角色或遮挡 Logo。
- 欢迎页与底部输入区切换时复用同一个按钮/SVG/引擎，用 Web Animations FLIP 完成 950 ms 转移；途中可打断，清理旧动画。缩放窗口只重新适配，不横穿输入控件。
- 浮动范围扩大为宽屏 ±7/±10 px，周期延长为 14 秒；鼠标视线取消原有 240 px 限制，仍限制视角幅度，身体吸附范围保持小而有界。
- 独立的单一随机定时器在 20–40 秒后选择一个不与上次相同的特殊动作。动作、飞行或近 5 秒内有输入时顺延；手动操作重排间隔，后台/离屏/减少动态时取消，不补播历史动作。
- 测试覆盖欢迎落点、随机区间与去重、飞行打断/减少动态、定时器卸载；浏览器覆盖手机欢迎页、真实会话切换、宽度变化及自动触发。

## 边界与验证

- 只修改输入框左侧的独立伴随按钮；原生输入保持第一子节点，原生发送工具栏保持最后子节点。
- 帧循环不查询布局、不增加 SVG 节点；离屏/后台暂停，减少动态模式冻结。
- 自动测试覆盖轮廓比例、眼睛、体积和插值边界、连续点击、双击接续、原生发送结构、生命周期与移动布局。
- 浏览器检查浅/深色、390–1920 px 六种宽度，以及 120 Hz 采样下的动作边界。
