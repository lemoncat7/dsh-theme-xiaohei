# 御灵空间 · 0.5.0-rift.4

本轮保留白发人形小黑原画及深色工作台，补齐独立实现的空间交互。

- 42 个确定性分布的银绿灵光，共用原场景 WebGL 上下文和调度器；不是全屏高密度粒子模拟。
- 部分灵光在手边缓慢绕行，鼠标靠近时轻微收拢；角色脸部保留遮罩。
- 三块前景金属碎片轻微转动，反光由角度决定。
- 仅对话滚动容器驱动背景视差，背景不超过 10 CSS 像素，前景略快；不修改用户滚动位置。
- 发送、会话切换、执行完成时短暂出现裂隙能量流，不为普通点击触发背景闪光。
- 浅色侧栏和输入控件不变，消息改为深青半透明阅读层；回写提示及 Markdown 变量在消息内局部适配。
- 手动关闭、窗口失焦、隐藏、减少动态效果、移动窄屏和省流量时不运行场景循环。静态原画保底。

参考 React Bits 的 Particles / Antigravity / AeroShards 的视觉方向，未复制其引擎或引入新依赖。只使用既有主题与浏览器事件，未修改 DSH 核心、会话日志或其他插件。
