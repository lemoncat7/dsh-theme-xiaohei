## 实现与约束

`src/rift/sidebar-styles.ts` 独立管理侧栏装饰；`RiftResonance` 在原有 React 插槽内输出装饰 SVG，不替换任何宿主业务图标或状态标记。

- 不增加库、网络图片、观察器或定时器。
- 新增关键帧仅改变 transform / opacity；不动画布局、模糊或阴影。
- 装饰伪元素不接受鼠标事件；保留标题截断、菜单、hover 卡片、拖拽和键盘焦点。
- 复用 `data-rift-paused`，服从失焦、后台、动效开关和减少动态设置；窄屏静止，强制颜色模式保留系统选中轮廓。
- 删除旧的重复侧栏流光和柱状状态装饰，首屏入口仍在原有 55KB 测试预算内。
