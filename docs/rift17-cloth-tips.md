# 界隙 0.5.0-rift.17：衣角动、腰身不动

用户要求衣角摆动，反馈旧效果连腰一起扭动。旧衣摆区域以 `(1265,696)` 为中心、半径 `(190,97)`，覆盖腰部和裤子；仅固定手臂不足以保护身体，右侧建筑位移场也与人物轮廓重叠。

- 衣摆形变改为左侧自由衣角的小区域，半径由 `(190,97)` 缩到 `(40,34)`，靠衣服主体的连接处衰减为零。
- 对上衣主体、腰胯、双腿增加固定区域，并与原来的手臂/手指固定区域合并，阻止所有重叠位移场影响身体。
- 保留袖口自由末端的小幅摆动、建筑漂浮与原有头部/眼睛交互；不修改背景图片、不新增贴图或渲染循环。
- 保留 `.16` 的侧栏减法和输入框闪框修正。
