输入是原始 PNG 的 `(1010,360,1280,565)` 手部裁切。仅合成手部局部，
其余像素仍来自原始 PNG；没有采用模型重画的脸、背景或袖子。
`scripts/prepare-rift-scene.py` 固定画面坐标为 1672×940，保持动作标定兼容。
这不是 4K 重画或 AI 超分，源图本身的细节仍有分辨率上限。

## 清晰度与加载

参考 ui-ux-pro-max 的 Image Optimization / Image Scaling 建议：

- 启动 HTML 继续内联小图，深浅合计 126,444 字节，小于上一版 148,862 字节。
- 延迟背景模块使用原始 PNG 导出的质量 92 WebP，深浅合计 279,190 字节。
- 高清图未解码/加载失败时不遮住首屏底图，不用纯色占位。
- 角色 atlas 从同一高清源重建，脸仍直接采样场景，避免独立面部贴图色差。
- 1080p / DPR 1 使用 1920×1080，原来是 1440×810。
- 1440×900 / DPR 2 使用 2160×1350；DPR 最高按 1.5 计算，最多 300 万像素、2560 像素宽。
- WebGL 支持时使用 highp，避免以 mediump 做像素坐标形变造成精度损失；低端兼容回退保留。
- 维持单 WebGL context、18/24 帧上限及隐藏/失焦/减少动态/小屏暂停。

入口 50,154 字节；延迟装饰模块 441,905 字节。高清数据不进入主入口和启动 HTML。
提高分辨率会增加前台绘制开销，不能据无头软件渲染推断真实设备 GPU 占用。
