## 原创视觉提案：界隙

这是一项设计提案，不是官方世界观中的命名。

### 场景

大面积墨色负空间；一道偏离中心的斜向空间裂隙；由裂隙照亮的白发人形小黑；少量有体积与方向的金属碎片。白发用清晰灰阶保留发束和轮廓，不能过曝成白色光团。角色与背景一起构图，不做角落贴纸或悬浮头像。聊天正文落在安静区域，角色脸和手势避开正文。

需要重新制作场景远层、角色主体、前景碎片、边缘光遮罩。不得重染旧图或把旧图换位置冒充新设计。参考图只供人物形态核验，不直接进入发布包。

### 材质与配色

底色墨黑 `#0B0D12`，面板石墨 `#1C2028`，正文骨白 `#E8E5DE`，能量高光冷银 `#CBD9E5`，少量旧金 `#BBA06B`。角色本身保留官方识别需要的绿色，但不把所有界面涂绿。色值仅为概念起点，最终以实际合成画面的对比度测量确定。

浅色方案另行设计为冷白纸面、墨色裂隙及金属暗边，不能只反转深色。先验证深色主视觉；两种主题都必须可读。

### 左栏

窄的身份轨道加主导航板，石墨金属材质，不使用整块半透明圆角玻璃卡。
以细刻线、切角与局部明暗分隔层级。选中会话出现一条有方向的银色切面，hover 只触发局部反射；不画连续霓虹框。
折叠时面板沿边界收拢，图标保留位置；展开时文字随面板显现，不等待整段动画结束才可点击。

### 动效编排

| 状态 | 角色与场景 | 界面反馈 |
| --- | --- | --- |
| 首次进入 | 裂隙短暂开启，轮廓光显现，碎片归位 | 页面立即可操作，演出不拦加载 |
| 空闲 | 衣角、头发与少量碎片低幅度运动 | 面板保持安静 |
| 鼠标经过 | 碎片轻微偏转、局部光线变化 | 不改系统指针，不加跟手拖尾 |
| 发送 | 碎片短暂聚拢，裂隙发生一次能量传递 | 输入框边缘扫光一次 |
| 生成中 | 能量沿裂隙缓慢流动 | 维持清晰的原生状态提示 |
| 完成 | 碎片散开并归位，光线回落 | 一次短促的完成反馈，不重复闪烁 |
| 弹窗 | 场景降亮 | 面板短距展开，关闭更快；始终允许中断 |

不能用相同的整体上下浮动代替所有角色动作。不能对每个 token 重启动画。

## 开发前与交付验收

1. 先完成全新角色/场景构图与完整界面概念图（含侧栏、真实长度消息和输入框），检查人物准确性与辨识度。
2. 做单一主特效的动效样片，观察空闲、发送、生成、完成状态，而非只给静态效果图。
3. 再接插件：新视觉模块、新资源清单，不引用旧视觉资产和 CSS。
4. 验证大屏、普通笔记本和窄屏，正文无遮挡、弹窗居中、hover/拖拽正常。
5. 单一调度器、按需加载、动态分辨率、后台及失焦暂停、减少动态与无 WebGL 回退。实际 GPU/CPU 和加载时间测试后才能声称性能达标。
