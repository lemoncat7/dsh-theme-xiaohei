## 固定的效果

- 白发人形小黑；深色夜境与独立浅色日景。
- 浅色气泡从左侧半透明到右侧透明，保留文字可读性。
- 侧栏、会话、输入与运行状态联动；眼睛连续形变，建筑、手和衣摆运动。
- 五指手部及拇指轮廓局部修正；高清场景与轻量首屏分开加载。
- 单 WebGL context、18/24 帧上限、最多 300 万像素；失焦、后台、减少动态及窄屏暂停。

## 干净检出后的构建

使用 package.json 声明支持的 Node 版本，在仓库根目录执行：

```sh
npm ci
npm test
npm pack
```

构建使用仓库内的 WebP 素材与生成脚本，不需要本机图片输出目录、DSH 凭据或生图服务。
`assets.ts`、`detail-assets.ts`、`character-assets.ts` 等嵌入模块由构建重新生成，不提交重复的 base64。
`prepare-rift-scene.py` / `prepare-character-rig.py` 仅用于再次编辑素材；其原始生成输入路径见各次制作记录，日常构建无需运行它们。

`src/spirit-realm` 与旧主题源码保留用于历史比较和旧测试，不进入当前界隙运行包；构建检查会阻止旧视觉模块混入。
