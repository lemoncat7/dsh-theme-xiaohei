# 0.3.0

基于已验收的 `0.3.0-alpha.176` 发布正式版；不额外改变本版视觉或交互。

## 更新

- 日夜天空壁纸与高清罗小黑角色分层，宽屏坐姿、窄屏探头，保留托腮和打盹姿势；人物定位不再跟随输入框下沉。
- 统一侧栏磨砂材质、目录和会话状态，增大消息气泡横向留白；保留原生布局与业务交互。
- 输入框旁嘿咻支持慢浮动、鼠标视线、点击/双击动作、随机待机、思考与本轮结束提醒，发送键嘿咻保持独立。
- 修复输入框下沉时飞行动画被重复打断、重启；增强抬头幅度。
- 可选订阅官方当前会话状态，不读取消息、不发送请求或操作会话；背景独立于会话运行状态。
- 动画支持隐藏暂停、减少动态与卸载清理；素材按需解码，特效节点固定复用。

## 兼容性与验证

- DeepSeek Harness `0.1.2-rc.1`；Node.js `^22.19.0 || >=24.0.0`。
- 81 项测试：80 通过、1 项历史测试跳过。
- 已验证桌面和手机尺寸、深浅色、欢迎页转场、压力滚动、鼠标视线及减少动态模式。
- iOS / Android 软键盘适配仍需真机补充验收。
